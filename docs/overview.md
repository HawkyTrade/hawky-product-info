# Product overview

Hawky Trade helps users work with Solana market signals through configurable analysis, live market data, alerts, and position-management tools.

## User choice

A user can review a signal in Hawky, use the contract address for independent research, or—where supported and explicitly configured—use Hawky execution features. Hawky is designed to make these choices visible to the user.

## Wallet connection

Hawky does not offer WalletConnect or any flow for connecting an external wallet.

## Paper Mode

Paper Mode lets users explore Hawky's analysis and workflow using live market data with simulated execution. Paper Mode does not include an external-wallet connection step.

## Configurable workspace

Users can select the signal sources and preferences available to their account. Hawky presents information and tools; users remain responsible for their own decisions and for understanding the risks of digital assets.

## Availability

Features can vary by platform, account access, and user configuration. See [hawky.trade](https://www.hawky.trade) for current product information.
