# Hawky product updates

This page lists confirmed, user-visible product changes. Release availability and included features can vary by platform, distribution track, account access, and configuration.

For the latest version available to you, use the official links on [hawky.trade](https://www.hawky.trade). Release notes shown by an app store or distribution platform may contain additional platform-specific details.

Entries are listed newest first.

## November 2026 — Watchlist price projection (Local/Paper)

- Added an experimental probabilistic price corridor to open-position Watchlist charts when sufficient market data is available; charts keep their usual view when a projection cannot be supported.
- Projection duration follows the configured position hold period. Outcomes from eligible completed positions inform gradual calibration. The projection is informational and does not control trade execution.

## November 2026 — Optional Edge entry confirmation

- Added an optional Edge confirmation for standard Local entries in Paper and Live modes.
- When enabled, Edge evidence can hold an otherwise-qualified entry; the setting is off by default and remains under the user's control.

## October 2026 — Mobile update (1.0.7, code 11)

- Made navigation easier to scan with expandable menu groups.
- Unified visual styling and loading feedback across more areas of the platform.
- Improved responsiveness when opening analysis tools and switching between menus.
- Refined mobile session controls and alert presentation.
- Continued reliability and release-quality improvements.

## October 2026 — Website and mobile improvements

### Account access and setup

- Added self-service account creation with email-based activation.
- Made password setup clearer with visible requirements, confirmation feedback, and more reliable activation recovery.
- Improved account activation and sign-in recovery when a temporary verification or loading issue occurs.
- Made new accounts start with the currently enabled public menu set, while account-specific menu access remains configurable.
- Added clearer first-session guidance to help new users get started.
- Kept Paper and Live execution preferences separate where both modes are available.

### Signals and configurable analysis

- Expanded support for receiving signals from custom sources and reviewing incoming and qualified signals in Hawky.
- Expanded configurable signal-analysis options, including optional RSI-based entry controls.
- Improved the clarity of signal statuses and the information shown when reviewing a decision.
- Made qualified-signal alerts reflect configured entry and security checks.
- Added a quick CA-copy action on mobile, so users can choose how to use a signal.
- Added configurable alerts for selected token addresses; availability can depend on account access.
- Improved signal and market context in activity and monitoring views.

### Research and performance review

- Added Strategy Lab, Risk Center, and Strategy Ranking to help users review outcomes, assess risk, and compare strategies; availability can depend on account access.
- Added a Strategy Library for saving and reviewing strategy references.
- Added richer views for activity from tracked wallets and recent multi-wallet token activity.
- Added shareable result cards for fully closed simulated positions, with the total position outcome shown together.
- Made it easier to review Paper performance while keeping simulated results clearly identified.

### Positions and execution

- Improved position charts, quote-status visibility, and dashboard updates as positions change.
- Made position exposure and Paper performance easier to review.
- Added clearer sell-alert details, including the exit reason and SOL result.
- Refined position actions and confirmation dialogs to make sells easier to review on smaller screens.
- Improved precision when displaying SOL amounts in Live mode.
- Added clearer controls for continuing a configured Hawky session while the user is away.

### Notifications and mobile experience

- Added per-account push-notification preferences so users can choose which alert types they receive.
- Added alerts for qualified signals and additional trade events, with preferences saved per account.
- Improved notification delivery handling, the mobile notification center, alert dismissal, and read-state handling.
- Refined the placement and appearance of mobile notification, refresh, and session controls.
- Added iPhone and iPad guidance for installing Hawky as a Home Screen web app and enabling notifications.
- Improved the setup prompt for connecting a supported browser or installed web app to Hawky alerts.

### Interface and responsiveness

- Organized navigation into expandable groups and made menu loading states more consistent.
- Improved responsiveness when opening analysis tools and switching between menus.
- Refined desktop and mobile layouts, including clearer tables, position cards, exposure summaries, and action controls.
- Improved loading and recovery behavior after temporary connection or sign-in interruptions.
- Added direct links to Hawky's official mobile-store listings and social profiles.

## October 2026 — Android early access (1.0.4)

- Improved the mobile layout and session controls.

- Hawky Trade launched in the Solana Mobile dApp Store on October 23, 2026.

- Paper Mode uses live market data with simulated positions; no external wallet connection is required.
