# Scope of this public repository

This repository is limited to user-facing product information and general responsible-use guidance. It is intentionally separate from the Hawky application and private development repository.

It does not publish application source code, internal decision rules, server or deployment configuration, credentials, account or runtime data, databases, logs, release binaries, or private project history.

The documentation describes product behavior at a high level. Availability and exact behavior may vary by platform, account access, and configuration; the live product is the source of current availability information.
