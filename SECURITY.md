# Reporting a security concern

Please report suspected security issues privately through the contact channel listed on [hawky.trade](https://www.hawky.trade). Include a concise description and steps to reproduce when possible. Do not include wallet recovery phrases, private keys, passwords, access tokens, or other secrets in a report.

Hawky does not offer WalletConnect or any flow for connecting an external wallet. If a site claiming to be Hawky asks for an external-wallet connection or approval, close it and use [hawky.trade](https://www.hawky.trade). Never include recovery phrases or private keys in security reports.

Please allow the Hawky team reasonable time to investigate before publicly disclosing a suspected vulnerability. This repository contains product information only; do not use it to submit sensitive account or runtime data.
